觀察重點

  • 前十名仍由平台型專案主導，真正熱門的是「一組技能 + 一套工作流 + 一個操作面」，不是單顆 skill。
  • graphify、codegraph 與 open-design 同時在前段班，代表上下文壓縮、知識圖譜與產出介面正在匯流。
  • oh-my-openagent、ruflo、oh-my-codex 這類 harness / HUD / agent team 類 repo 仍強勢，顯示多人代理與長任務編排還是最吸睛主題。
  • VoltAgent/awesome-agent-skills、refly 與 khazix-skills 這類目錄或 builder 型 repo 本週存在感提高，skill 生態開始更重視分發與建立流程。

MIS / 技術人員注意項目

  • 先看權限面：許多 repo 會碰 shell、瀏覽器、MCP、雲端模型、檔案系統與 plugin 安裝，OA / PROD 分區要先確認邊界。
  • 背景執行要補 log：很多熱門 repo 預設互動式桌面流程，若要放進 SCCM、工作排程、服務或自動化平台，請補 log、exit code 與失敗重試策略。
  • 版本務必 pin：前段班幾乎都在高頻更新，建議先固定 tag 或 commit SHA，再進行驗證與內部導入。
  • 插件與 skill 內容要審核：不要只因為星數高就直接裝進企業工作站，至少要確認外連、執行腳本、憑證、token 存放與更新來源。

本週變化簡述

和 2026-07-25 那篇相比，前段班主軸沒有翻桌，但排序更明顯朝「高頻更新的工作台型 repo」集中。openai/codex、graphify、open-design、agent-skills 與 oh-my-openagent 仍站穩前排，說明上下文工程、設計工作台與 agent harness 依然是社群最買單的方向。

本週比較值得記三點：第一，VoltAgent/awesome-agent-skills、KKKKhazix/khazix-skills、teng-lin/notebooklm-py 與 refly 這類 skill catalog / builder / 知識工作流專案抬頭；第二，上週入榜的 wshobson/agents 與 OthmanAdi/planning-with-files 因最近 push 早於 2026-07-25，這次不在榜內；第三，榜單仍可列滿 20 個，表示 Codex skill 相關生態在過去一週並沒有降溫。

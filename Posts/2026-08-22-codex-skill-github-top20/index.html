  • 前段榜單不再只是 skill pack，而是「skills + memory + sandbox + plugin + workbench」整包能力，平台化更明顯。
  • 本週比上週更常看到 design plugin、memory layer、long-horizon harness 這類長任務配套能力，代表 Codex 相容生態正在往完整工作台演進。
  • 官方維護 repo 仍有存在感，像 anthropics/skills、vercel-labs/agent-skills、google/skills、dotnet/skills 都還在更新。
  • NVIDIA/SkillSpector 仍在榜上，說明社群對 skills / plugins 的供應鏈風險與審查需求持續升溫。

MIS / 技術人員注意項目

  • 不要只看 README：越前段的 repo 越常夾帶 CLI、MCP、plugin、記憶層與背景流程，導入前要看實際執行邊界。
  • 把技能包當可執行供應鏈管理：版本 pin、來源白名單、審查流程與回滾機制要先準備，不然更新速度會超過維運能力。
  • 權限與網路切區要先做：這類工具常碰原始碼、文件、瀏覽器、憑證與外部 API，OA 與受限環境最好分開驗證。
  • 長任務功能不等於可無腦上線：memory、subagents、plugin orchestration 越完整，越要補日誌、審計與資料流檢查。

本週變化簡述

和 2026-08-15 那篇相比，這週更像是「整套 agent 能力平台」的競賽。榜首到前十名裡，越來越多不是單純技能包，而是把 skill 發現、記憶管理、視覺插件、工作台與長任務編排一起打包。

另一個明顯變化是官方與企業導向 repo 的存在感更強，像 google/skills、dotnet/skills 與 NVIDIA/SkillSpector 都反映出「技能生態要治理」這件事正在成形，不再只是社群玩具。
